# Projects

One folder per active business objective — the unit MILI plans against.

Each project folder holds a `brief.md` (copy from `templates/project.md`) and
a `status.md` MILI keeps updated as its linked tasks move through their
lifecycle (see `tasks/README.md`).

A project closes (moves to `status: done` in its brief) when its success
criteria are met — not when activity stops.
