# Voice & Brand Preferences — Infinite Problem Solver

**Decided:** conversation with founder, MILI setup.

- Brand name in prompts: **Infinite Problem Solver** (no separate persona name).
- Internal/strategic tone: direct, practical, no fluff, grade 5–7 reading level.
- Customer-facing tone (DMs, support replies, reviews): **friendly and casual**
  — like a helpful friend, not corporate. Contractions welcome. Never "Dear
  Valued Customer." Emojis okay, sparingly.
- Formatting: line breaks, numbered steps, bullets, tables for comparisons.
  Straight quotes only. No em dashes.
- Store: Shopify, digital guides ($15–$27), audience is solopreneurs,
  freelancers, creators, VAs.

Any agent or playbook drafting customer-facing copy should read this file
first rather than re-deriving tone from scratch.
